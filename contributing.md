# Contributing to Market Oracle

Thanks for your interest in contributing! We welcome all contributions.

## How to Contribute

### Quick Start

1. **Fork the repository** and clone it locally
2. **Create a branch** for your changes (`git checkout -b feature/your-idea`)
3. **Make your changes** and test them
4. **Commit** with a clear message
5. **Push** to your fork and open a Pull Request

### What You Can Contribute

- Bug fixes
- New features or improvements
- New data sources or scrapers
- Documentation updates
- Tests
- Any other improvements you think would help

### Guidelines

- Keep changes focused and clear
- Test your changes before submitting
- Write clear commit messages
- Update documentation if needed

That's it! We keep things simple and flexible.

## Questions?

Open an issue or discussion on GitHub - we're happy to help!
